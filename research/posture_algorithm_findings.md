# 基于上半身关键点的体态检测算法研究

## 来源

## 关键发现

### 1. 核心算法：使用两个角度判断体态

该方法使用**侧面视角**，通过计算两个关键角度来判断体态：

#### 角度1：颈部倾斜角（Neck Inclination）
- **定义**：肩膀-耳朵连线与垂直轴的夹角
- **关键点**：
  - P1: 肩膀 (shoulder)
  - P2: 耳朵 (ear)
  - P3: 肩膀正上方的点（垂直轴上）
- **正常阈值**：< 40度
- **用途**：检测头部前倾

#### 角度2：躯干倾斜角（Torso Inclination）
- **定义**：髋部-肩膀连线与垂直轴的夹角
- **关键点**：
  - P1: 髋部 (hip)
  - P2: 肩膀 (shoulder)
  - P3: 髋部正上方的点（垂直轴上）
- **正常阈值**：< 10度
- **用途**：检测驼背/含胸

### 2. 角度计算方法

```python
def findAngle(x1, y1, x2, y2):
    """
    计算两点连线与垂直轴的夹角
    (x1, y1): 基准点（下方点）
    (x2, y2): 目标点（上方点）
    """
    theta = m.acos((y2 - y1)*(-y1) / (m.sqrt((x2 - x1)**2 + (y2 - y1)**2) * y1))
    degree = int(180/m.pi) * theta
    return degree

# 计算颈部和躯干倾斜角
neck_inclination = findAngle(l_shldr_x, l_shldr_y, l_ear_x, l_ear_y)
torso_inclination = findAngle(l_hip_x, l_hip_y, l_shldr_x, l_shldr_y)
```

### 3. 体态判断逻辑

```python
if neck_inclination < 40 and torso_inclination < 10:
    # 良好坐姿
    good_frames += 1
    bad_frames = 0
else:
    # 不良坐姿
    bad_frames += 1
    good_frames = 0
```

### 4. 关键问题：需要髋部关键点

**重要发现**：该算法的躯干倾斜角计算**必须使用髋部关键点**！

```python

```

**这与我们的坐姿场景冲突**：
- 坐在桌子前时，髋部通常被遮挡
- YOLOv8-Pose可能检测不到髋部关键点
- 原算法无法直接应用

## 5. 解决方案：修改算法以适应坐姿场景

### 方案A：使用颈部-肩膀-肘部角度替代躯干角度

**思路**：驼背时，上半身整体前倾，肘部会相对肩膀更靠前

```python
# 计算肩膀-肘部倾斜角（替代躯干角）
upper_torso_inclination = findAngle(l_shldr_x, l_shldr_y, l_elbow_x, l_elbow_y)
```

**优点**：
- 只需要上半身关键点
- 肘部在坐姿下通常可见

**缺点**：
- 手臂姿势会影响检测（如手放桌上、手托腮等）
- 需要重新标定阈值

### 方案B：使用肩膀高度相对于头部的位置

**思路**：驼背时，肩膀会相对头部更靠前

```python
# 计算肩膀相对鼻子的前后位置

head_height = abs(nose_y - shoulder_mid_y)
forward_ratio = shoulder_forward_offset / head_height
```

**优点**：
- 不依赖髋部
- 不受手臂姿势影响

**缺点**：
- 需要侧面视角
- 正面视角效果不佳

### 方案C：只检测头部前倾，放弃驼背检测

**思路**：头部前倾和驼背往往同时出现，检测头部前倾即可

## 6. 推荐方案

### 针对坐姿场景的修订算法

**检测项目调整**：

1. ✅ **头部前倾**（完全可行）
   - 使用：肩膀-耳朵角度
   - 阈值：< 40度为正常

2. ✅ **高低肩**（完全可行）
   - 使用：左右肩膀高度差
   - 阈值：高度差/肩宽 < 5%为正常

3. ⚠️ **圆肩**（部分可行）
   - 使用：肩膀-肘部位置关系
   - 需要检查肘部置信度

4. ⚠️ **驼背**（需要修改）
   - **方案1**：使用肩膀-鼻子的前后位置比例（侧面视角）
   - **方案2**：通过头部前倾间接判断（简化方案）
   - **方案3**：使用肩膀-肘部角度（受手臂姿势影响）

5. ⚠️ **身体倾斜**（需要修改）
   - 使用：肩膀中点-鼻子连线与垂直轴的偏移
   - 或：双肩连线的水平倾斜度（但会与高低肩混淆）

## 7. 关键结论

1. **MediaPipe的算法依赖髋部关键点**，不能直接应用于坐姿场景
2. **必须重新设计算法**，只使用上半身关键点（头部、肩膀、肘部）
3. **侧面视角效果最好**，可以更准确地检测头部前倾和驼背
4. **正面视角**适合检测高低肩和身体倾斜
5. **建议优先实现头部前倾和高低肩检测**，这两项最可靠
