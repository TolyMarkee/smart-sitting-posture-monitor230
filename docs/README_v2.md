# 坐姿体态检测DEMO - 使用说明

## 项目简介

本项目基于庐山派K230开发板和YOLOv8-Pose人体关键点检测模型，实现了实时坐姿体态问题检测功能。

**重要说明**：本项目专门针对坐姿场景优化，只使用上半身关键点进行检测，适用于办公和学习场景。

---

## 可检测的体态问题

### P0优先级（必须实现，准确率 ≥ 80%）

#### 1. 头部前倾（Forward Head Posture）
- **表现**：头部向前伸出，颈部过度前倾
- **检测方法**：计算耳朵-肩膀连线与垂直轴的夹角
- **判断标准**：
  - 正常：< 40度
  - 轻度：40-50度
  - 中度：50-60度
  - 重度：≥ 60度
- **所需关键点**：耳朵、肩膀

#### 2. 高低肩（Uneven Shoulders）
- **表现**：两肩高度不一致
- **检测方法**：计算左右肩Y坐标差值与肩宽的比例
- **判断标准**：
  - 正常：< 5%
  - 轻度：5-8%
  - 中度：8-12%
  - 重度：≥ 12%
- **所需关键点**：左右肩

### P1优先级（应该实现，准确率 ≥ 70%）

#### 3. 驼背/含胸（Hunched Back）
- **表现**：上半身过度前倾
- **检测方法**：计算肩膀相对鼻子的前后位置比例（修订算法）
- **判断标准**：
  - 正常：< 0.3
  - 轻度：0.3-0.5
  - 中度：0.5-0.7
  - 重度：≥ 0.7
- **所需关键点**：鼻子、肩膀
- **注意**：此为修订算法，阈值可能需要根据实际测试调整

#### 4. 身体倾斜（Body Tilt）
- **表现**：身体整体向左或右侧倾斜
- **检测方法**：计算肩膀-鼻子连线与垂直轴的偏移角度（修订算法）
- **判断标准**：
  - 正常：< 5度
  - 轻度：5-10度
  - 中度：10-15度
  - 重度：≥ 15度
- **所需关键点**：鼻子、肩膀

### P2优先级（可选实现，依赖肘部可见性）

#### 5. 圆肩（Round Shoulders）
- **表现**：肩部向前内旋
- **检测方法**：计算肩部前移距离与肩宽的比例
- **判断标准**：
  - 正常：< 0.2
  - 轻度：0.2-0.3
  - 中度：0.3-0.5
  - 重度：≥ 0.5
- **所需关键点**：肩膀、肘部
- **注意**：手放桌上时肘部可能被遮挡，此时跳过检测

## 技术特点

### 1. 针对坐姿场景优化
- **问题**：坐在桌子前时，下半身（髋部、膝盖、脚踝）被遮挡
- **解决**：重新设计算法，只使用上半身11个关键点
- **优势**：适用于真实办公/学习场景

### 2. 关键点定义（COCO格式）
YOLOv8-Pose检测17个关键点：
- **头部**（5个）：鼻子、左右眼、左右耳 ✅ 可见
- **上肢**（6个）：左右肩、左右肘、左右腕 ✅ 可见
- **下肢**（6个）：左右髋、左右膝、左右踝 ❌ 通常遮挡

### 3. 算法修订说明
- **传统算法**（如MediaPipe）依赖髋部关键点计算躯干角度
- **修订算法**：驼背和身体倾斜改用肩膀-鼻子位置关系
- **权衡**：P1项目精度从80%降至70%，但适用于坐姿场景

## 使用方法

### 硬件要求
- 庐山派K230开发板
- CSI2接口摄像头
- 3.1寸LCD屏幕或HDMI显示器

### 软件环境
- CanMV固件（已预装YOLOv8-Pose模型）
- CanMV IDE K230

### 运行步骤

1. **准备开发板**
   - 确保TF卡中已安装CanMV固件
   - 连接摄像头和显示设备
   - 上电启动开发板

2. **上传代码**
   - 打开CanMV IDE
   - 连接开发板
   - 将所有Python文件上传到 `/sdcard/app/posture_detection/` 目录

3. **运行程序**
   - 在IDE中打开 `main.py`
   - 点击运行按钮
   - 或在开发板上执行：`python3 /sdcard/app/posture_detection/main.py`

4. **查看结果**
   - 屏幕上会实时显示人体骨架
   - 检测到的体态问题会以文字形式显示
   - 不同严重程度用不同颜色标识：
     - 🟢 绿色：坐姿良好
     - 🟡 黄色：轻度异常
     - 🟠 橙色：中度异常
     - 🔴 红色：重度异常

## 配置选项

### 显示模式
在 `main.py` 中修改：
```python
display_mode = "lcd"  # 或 "hdmi"
```

### 检测阈值
在 `config.py` 中修改 `POSTURE_THRESHOLDS`：
```python
POSTURE_THRESHOLDS = {
    'forward_head': {
        'normal': 40,      # 调整此值改变敏感度
        'mild': 50,
        'moderate': 60
    },
    # ... 其他阈值
}
```

### 关键点置信度
在 `config.py` 中修改：
```python
KEYPOINT_CONFIG = {
    'confidence_threshold': 0.5,  # 调整此值改变关键点过滤标准
}
```

## 使用建议

### 1. 摄像头摆放
- **最佳角度**：侧面45度
- **推荐距离**：1-2米
- **画面范围**：确保上半身在画面中
- **高度**：与头部齐平或略高

### 2. 环境要求
- **光线**：充足且均匀，避免逆光
- **背景**：简洁，减少干扰
- **对比度**：人物与背景有一定对比度

### 3. 使用场景
- **办公**：放置在显示器旁边
- **学习**：放置在书桌一侧
- **建议**：长时间使用电脑时开启

### 4. 注意事项
- 首次使用建议先在正常坐姿下测试，了解基准状态
- 检测结果仅供参考，不能替代专业医学诊断
- 长期体态问题建议咨询专业康复师或医生
- 可以根据实际情况调整阈值参数

## 常见问题

### Q1: 检测不到人体怎么办？
**A:** 
- 检查摄像头连接是否正常
- 确保人物在画面中央
- 调整光线条件
- 降低 `confidence_threshold` 参数（在 `main.py` 中）

### Q2: 检测结果不准确？
**A:**
- 调整阈值参数（在 `config.py` 中）
- 改善拍摄角度（建议侧面45度）
- 确保关键点检测置信度足够高
- 保持相机稳定

### Q3: 圆肩检测不工作？
**A:**
- 圆肩检测依赖肘部可见性
- 如果手放在桌面上，肘部可能被遮挡
- 此时系统会自动跳过圆肩检测
- 建议手臂自然下垂或放在扶手上

### Q4: 驼背检测不准确？
**A:**
- 驼背检测使用修订算法，精度可能较低
- 建议使用侧面视角以提高准确性
- 可以在 `config.py` 中调整 `hunched_back` 阈值
- 阈值需要根据实际情况调整

### Q5: 如何优化性能？
**A:**
- 降低输入分辨率（在 `main.py` 中修改 `rgb888p_size`）
- 减少显示内容
- 优化代码中的循环和计算
- 当前配置应该可以达到 ≥ 10 FPS

### Q6: 能否保存检测结果？
**A:**
- 当前版本不支持数据记录
- 可以自行扩展代码添加记录功能
- 注意TF卡的读写速度
- 建议定期保存而非实时保存
